DOCUMENT ANALYSIS SCRIPTS
==========================

atento_document_orphans.sql
  Purpose: Find documents that exist in S3 but not in the database (orphans).
  Query:
    SELECT s.id AS orphan_id
    FROM s3_document_ids s
    LEFT JOIN attachments a ON a.attachable_id = s.id AND a.type = 'DocumentAttachment'
    WHERE a.id IS NULL;
  Result: 83 orphan documents

atento_document_missing.sql
  Purpose: Find documents that exist in the database but not in S3 (missing files).
  Query:
    SELECT a.attachable_id AS missing_id
    FROM attachments a
    LEFT JOIN s3_document_ids s ON s.id = a.attachable_id
    WHERE a.type = 'DocumentAttachment' AND s.id IS NULL;
  Result: 7 missing documents (explained - PasswordDocument by design)

atento_document_missing_state.sql
  Purpose: Check the state of missing documents to understand why files are missing.
  Query:
    SELECT d.id, d.type, d.state, d.filename
    FROM documents d
    WHERE d.id IN (SELECT a.attachable_id FROM attachments a
                   LEFT JOIN s3_document_ids s ON s.id = a.attachable_id
                   WHERE a.type = 'DocumentAttachment' AND s.id IS NULL);
  Finding: 6 are PasswordDocument with state=3 (final) - files removed by design after processing.

atento_document_150_check.sql
  Purpose: Verify specific document ID 150.
  Query:
    SELECT * FROM documents WHERE id = 150;
  Finding: Document doesn't exist in database - query error in original analysis.

atento_document_analysis.sql
  Purpose: Comprehensive document analysis combining multiple checks.

shared_document_orphans.sql
  Purpose: Check if orphan documents exist in the shared database (belong to other companies).
  Query:
    SELECT a.attachable_id AS doc_id, d.type AS doc_type, d.filename,
           c.id AS company_id, c.name AS company_name
    FROM attachments a
    JOIN documents d ON d.id = a.attachable_id
    JOIN companies c ON c.id = d.company_id
    WHERE a.type = 'DocumentAttachment'
    AND a.attachable_id IN (85078,80281,84998,...) -- 83 IDs
    ORDER BY c.name;
  Finding: Only 3 documents found (Brisanet and Rede Brasil). 80 don't exist anywhere.

shared_document_missing.sql
  Purpose: Verify missing documents in shared database.


SIGNATURE ANALYSIS SCRIPTS
===========================

atento_signature_orphans.sql / atento_signature_orphans_query.sql
  Purpose: Find signatures that exist in S3 but not in the database.
  Query:
    SELECT s.id AS orphan_id
    FROM s3_signature_ids s
    LEFT JOIN signatures sig ON sig.id = s.id
    WHERE sig.id IS NULL;
  Result: 0 orphans

atento_signature_missing.sql
  Purpose: Find signatures that exist in the database but not in S3.
  Query:
    SELECT sig.id AS missing_id
    FROM signatures sig
    LEFT JOIN s3_signature_ids s ON s.id = sig.id
    WHERE s.id IS NULL;
  Result: 9 missing (false positives - created after CSV extraction)

atento_signature_missing_state.sql
  Purpose: Check state of missing signatures.
  Finding: All 9 were created on 2026-01-01, after the S3 CSV was extracted.

shared_signature_missing.sql
  Purpose: Verify missing signatures in shared database.

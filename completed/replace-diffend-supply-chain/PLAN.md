# PLAN - Replace Diffend with Supply Chain Security Stack

## Objective

Remove the abandoned Diffend bundler plugin (incompatible with Bundler 4.x / Ruby 4.0.2) from
all 4 Ruby on Rails repositories and replace it with an equivalent open-source security stack.
This work is combined with the Rails version bump from 8.1.2 to 8.1.2.1 in the same branch and
PR per repository.

## Scope

### In Scope
- Remove `plugin 'diffend'` and `gem 'diffend-monitor'` from all Gemfiles
- Delete `.diffend.yml` from all repos
- Remove `.bundle/plugin/` directory from all repos (not tracked by git, but must be cleaned locally)
- Remove DIFFEND_* env vars and build-args from all GitHub Actions workflows
- Remove `.diffend.yml` COPY instruction from all CI Dockerfiles
- Remove DIFFEND ARG declarations from integrator Dockerfile
- Add `bundler-audit` gem (CVE scanning) to all repos
- Add `license_finder` gem (license compliance) to all repos
- Enable Bundler checksums (tampering verification) in all repos
- Add `bundler-audit` and `license_finder` CI steps to all repos
- Install Socket.dev GitHub App on all 4 repositories (manual step, done once)
- Bump Rails to `8.1.2.1` in all repos (already done in Gemfiles; run `bundle update` unblocked)
- Update `CHANGELOG.md` in all repos
- One commit + one PR per repository

### Out of Scope
- Gem source whitelist (no equivalent tool; deferred)
- Private gem source regex matching (deferred)
- Version bump approval workflow (covered by Dependabot + PR reviews)
- Mend SCA migration (retired Diffend features already pointing to Mend; no action needed)
- Any changes to `onboarding` beyond Diffend removal and Rails bump (no additional security tooling
  differences from other repos)

    runs-on: ubuntu-latest
    environment: Test
    timeout-minutes: 5
    steps:
      - uses: actions/checkout@v4
      - uses: ruby/setup-ruby@v1
        with:
          ruby-version: "4.0.2"
          bundler-cache: true
      - run: bundle exec bundler-audit check --update
        timeout-minutes: 5

    name: License Finder (License Compliance)
    runs-on: ubuntu-latest
    environment: Test
    timeout-minutes: 5

        with:
          ruby-version: "4.0.2"
          bundler-cache: true
      - run: bundle exec license_finder
        timeout-minutes: 5

## Technical Decisions

| Decision | Choice | Rationale |
|----------|--------|-----------|
| CVE scanning | `bundler-audit` | Drop-in replacement for the retired Diffend CVE feature; widely adopted, actively maintained |
| License compliance | `license_finder` | Only Ruby-native tool with CI integration; covers the retired Diffend license feature |
| Tampering verification | `bundle lock --add-checksums` | Native Bundler 2.5+ feature; no extra gem needed; verified on install |
| Typosquatting / malware | Socket.dev GitHub App | Free tier; no in-repo config needed; checks on every PR |
| Gem source whitelist | Not replaced | No equivalent OSS tool exists; deferred pending business need |
| Bundle execution | Remove Diffend plugin entirely | Plugin is abandoned and incompatible with Bundler 4.x; no runtime replacement needed |
| Branch strategy | `feature/bump-rails-8.1.2.1` (existing) | Rails bump and Diffend removal are bundled in one PR per repo to minimize merge cycles |
| Bundler version | Keep repo-specific versions (2.7.1 / 2.6.3) | Already on Bundler 2.x in Dockerfiles; no need to upgrade for this change |

## Risks

| Risk | Impact | Mitigation |
|------|--------|------------|
| `license_finder` flags existing gems as unapproved | Medium — CI fails on first run | Run `license_finder` locally first; approve known licenses with `license_finder whitelist add` before pushing |
| `bundler-audit` database is stale in CI | Low — false negatives, not failures | The `--update` flag fetches latest advisory DB on every run |
| Bundler checksums cause `bundle install` failures after gem yanking | Low — deployment blocked | Checksums verify tamper; a yanked gem is a real security event; acceptable tradeoff |
| Socket.dev marks a legitimate gem as suspicious | Low — PR check warning | Review Socket.dev findings case by case; can approve exceptions in dashboard |
| Removing `.bundle/plugin/` locally breaks other active branches | Low | `.bundle/` is gitignored; plugin dir is local state only; safe to delete |

## Assumptions

- All 4 feature branches (`feature/bump-rails-8.1.2.1`) already exist and have the Rails version
  bumped in `Gemfile` — only `bundle update` and Diffend removal remain
- Socket.dev free tier is sufficient (no private gem scanning needed)
- `license_finder` default behavior is acceptable as a starting point; a `config/license_finder.yml`
  or `.license_finder.yml` can be added later if licenses need explicit management
- Phases 2–5 are independent and can be executed in parallel or in any order
- The `integrator` Dockerfile does not COPY `.diffend.yml` — confirmed by inspection
- The `onboarding` CI workflow has no DIFFEND env vars — confirmed by inspection
- GitHub organization admin access is available for Socket.dev App installation

## RELATÓRIO FINAL: parseInt() Calls Feeding GraphQL ID Variables

Realizei uma busca abrangente por todas as chamadas `parseInt()` no codebase que alimentam variáveis GraphQL ID. Encontrei **~60 ocorrências** de bugs onde `parseInt()` converte IDs para números quando o backend GraphQL espera strings.

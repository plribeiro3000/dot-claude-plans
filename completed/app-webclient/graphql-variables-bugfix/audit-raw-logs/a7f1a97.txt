### CATEGORIA 3 - Boolean Parameters Not Converted From String

#### Bug 3.1: plan.service.ts - Variables override and shared não convertem de string
**Arquivo:** `/Users/plribeiro3000/Projects/4Shark/app-webclient/src/app/plan/plan.service.ts`
**Linhas:** 61-62 e 73-74

**Código atual:**
```typescript
if (params.override !== undefined && params.override !== null) {
  variables.override = params.override;
}
...
if (params.shared !== undefined && params.shared !== null) {
  variables.shared = params.shared;
}
```

**Problema:** Se `params.override` e `params.shared` forem strings (como `"true"` ou `"false"`), elas não são convertidas para boolean. Deveriam ser:

```typescript
if (params.override !== undefined && params.override !== null && params.override !== '') {
  variables.override = params.override === 'true';
}
...
if (params.shared !== undefined && params.shared !== null && params.shared !== '') {
  variables.shared = params.shared === 'true';
}
```

(Comparar com linha 52-54 onde `params.enabled` é corretamente convertido com `params.enabled === 'true'`)

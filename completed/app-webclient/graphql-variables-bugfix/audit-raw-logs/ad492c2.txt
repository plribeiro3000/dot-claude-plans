### Impacto

Quando um usuário tenta salvar um deal, collaborative deal ou métrica com qualquer desses campos numéricos definido como `0`, o valor não será incluído na mutação GraphQL, causando:
- Perda silenciosa de dados
- Comportamento inesperado onde 0 não é salvo
- Inconsistência de dados entre o formulário e a API

Todos os 12 problemas identificados precisam de correção.

=== PAPER: Code Change Characteristics and Description Alignment ===
=== A Comparative Study of Agentic versus Human Pull Requests ===
Published: Accepted at 23rd International Conference on Mining Software Repositories (MSR '26)

ABSTRACT KEY DATA:
- 33,596 agent-generated PRs (APRs) analyzed
- 6,618 human PRs (HPRs) analyzed

PR DESCRIPTION QUALITY FINDINGS (verbatim from paper summary):
"Agents generate stronger commit-level messages (semantic similarity 0.72 vs. 0.68) but lag humans at PR-level summarization (PR-commit similarity 0.86 vs. 0.88)"

"Commit message length is the best predictor of description quality"

CODE CHURN FINDING:
"APR-introduced symbols (functions and classes) are removed much sooner than those in HPRs (median time to removal 3 vs. 34 days)"
"symbol churn 7.33% vs. 4.10%"

AGENTS STUDIED: The paper analyzes agent-generated PRs in aggregate — it does NOT identify specific agent tools (Codex, Devin, Copilot, etc.) in the abstract.

SENSITIVE DATA FINDING: None. The paper does NOT study the content of PR descriptions for sensitive/business/infrastructure data. Research focus is on: code change characteristics, commit message quality vs. semantic alignment with code changes, and PR acceptance metrics.

RELEVANCE TO THIS SPIKE:
The academic literature on agentic PRs studies description QUALITY (does the description accurately reflect the code change?) not description CONTENT GOVERNANCE (does the description include data that should not be in GitHub?). The question of agent over-sharing sensitive data in PR prose is not studied in this or related papers.

# Source: ~/Projects/4Shark/dot-claude/scripts/inject-skill-tip.sh:71-86

# The skill tip hook fires on UserPromptSubmit and SubagentStart.

# Rate-limit: one tip per skill per session (marker file in /tmp/).
# Not required for skill to function — only for proactive surfacing.

# ============================================================
# SKILL CONTENT PATTERN — WHAT SKILL.MD DOES
# ============================================================
# Both post-mortem and integration-debug follow the same structure:
#
# 1. YAML frontmatter (name + description)
# 2. Role declaration ("You are the engineer's pair for X")
# 3. Mandatory context loading ("Before doing anything else — read these files")
# 4. Pre-condition questions ("Before generating content — ask for the basics")
# 5. Step-by-step flow with concrete instructions per phase/section
# 6. Output destination (where to write the result)
# 7. Refusal list (what to not produce)
# 8. Communication style reminder
#
# For /runbook, the pattern is simpler — no output file, no multi-step flow.
# The skill loads the INDEX.md, matches against the engineer's query, reads
# the matched runbook file, and walks the engineer through its steps.

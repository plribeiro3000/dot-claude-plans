### Step 4 — Pre-flight Validation Pipeline (PR #2115 — merged)

Replaced inline health checks and API authentication in ManagedIntegrator
with a multi-stage producer/consumer pipeline. Design evolved from a single
"absorb into ManagedIntegrator" approach to a proper pipeline with dedicated
workers per concern.

**Pipeline flow:**
1. `ManagedIntegrator` → checks enabled streams (if none: `MissingStreamsReport`) → creates Job → `HealthCheck::Producer`
2. `HealthCheck::Producer/Consumer/Finalizer` — checks reachability per source → `Authorization::Producer`
3. `Authorization::Producer/ApiConsumer/DatabaseConsumer/Finalizer` — checks auth (API) and permissions+locks (DB) → `ThroughputProcessor`
4. `ThroughputProcessor` — if normalized source exists: sets database_version/integration_version, calculates throughput → `Subsidiary::ManagedExtractorProducer`
5. On any failure: `PreflightReport::Producer/Consumer` — email with two sections (unreachable sources + authorization failures)

**New model:** `Preflight` (belongs_to :job, :source) with `reachable` (boolean), `status` (enum: pending/passed/failed), `failure` (enum: missing_permissions/open_transactions/connection_error/authentication_error), `detail` (string for exception messages)

- [x] `Preflight` model with enumerize scopes
- [x] `HealthCheck::Producer/Consumer/Finalizer` — reachability check per source
- [x] `Authorization::Producer` — dispatches ApiConsumer/DatabaseConsumer per source type
- [x] `Authorization::ApiConsumer` — HTTP auth, saves AuthenticationResponse
- [x] `Authorization::DatabaseConsumer` — normalized: pass, managed: permissions + locks
- [x] `Authorization::Finalizer` — checks unreachable + failed, dispatches report or continues
- [x] `ThroughputProcessor` — throughput only for normalized sources, sets versions once
- [x] `MissingStreamsReport::Producer/Consumer` — email when no active streams (no Job created)
- [x] `PreflightReport::Producer/Consumer` — email with unreachable + failed sections, i18n (en/pt-BR/es)
- [x] `ManagedIntegrator` simplified — checks streams, creates Job, calls HealthCheck::Producer
- [x] 24 managed extractor producers: `is_a?(DatabaseSource)` → `source.database?`
- [x] DatabaseWarmer retry logic deferred to Step 7 cleanup (not needed with new pipeline)

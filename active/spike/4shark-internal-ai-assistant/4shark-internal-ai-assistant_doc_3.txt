Name clarification: The Claude Agent SDK is the programmatic runtime previously documented as "Claude Code SDK". It exposes the same agent loop that powers Claude Code as a library.

Python package: claude_agent_sdk
TypeScript package: @anthropic-ai/claude-agent-sdk

Minimal Python usage:
"""
import asyncio
from claude_agent_sdk import query, ClaudeAgentOptions

async def main():
    async for message in query(
        prompt="Find and fix the bug in auth.py",
        options=ClaudeAgentOptions(allowed_tools=["Read", "Edit", "Bash"]),
    ):
        print(message)

asyncio.run(main())
"""

Message types emitted by query():
- SystemMessage (subtype: "init") — session metadata, MCP server status
- AssistantMessage — Claude's text and tool calls
- ResultMessage (subtype: "success" | "error_during_execution") — final result

Built-in tools available (no extra config):
- Read, Edit, MultiEdit — file read/write
- Bash — shell execution (sandboxed)
- WebFetch, WebSearch — web access
- NotebookRead, NotebookEdit — Jupyter notebooks
- All MCP tools via allowedTools wildcard

Sessions:
- Each query() call is a stateless single conversation turn by default
- Persistent sessions require passing a session_id for multi-turn continuity

System prompt customization:
"""
options = ClaudeAgentOptions(
    system_prompt="You are an internal assistant for 4Shark's support team...",
    model="claude-sonnet-4-6",
)
"""

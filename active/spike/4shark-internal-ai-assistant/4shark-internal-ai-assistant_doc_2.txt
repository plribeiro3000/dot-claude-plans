KEY VERBATIM QUOTES:

Overview:
"Claude can analyze data, create visualizations, perform complex calculations, run system commands, create and edit files, and process uploaded files directly within the API conversation. The code execution tool allows Claude to run Bash commands and manipulate files, including writing code, in a secure, sandboxed environment."

Pricing:
"Code execution is free when used with web search or web fetch. When web_search_20260209 (or later) or web_fetch_20260209 (or later) is included in your request, there are no additional charges for code execution tool calls beyond the standard input and output token costs. Standard code execution charges apply when these tools are not included."

Sandbox environment (from search result corroboration):
- Ubuntu 24.04.2
- 9GB RAM
- ~5GB disk space
- Python 3.12.3 pre-installed
- Node.js 18.19.1 pre-installed
- Pre-installed: pandas, numpy, matplotlib, and other data science libraries
- Can install additional packages via pip on demand

Tool versions:
- code_execution_20250825: "supports Bash commands and file operations and is available on every model"
- code_execution_20260120: "adds REPL state persistence and programmatic tool calling from within the sandbox"
- code_execution_20260521: "same runtime as _20260120 with the per-cell execution time limit disclosed in the tool description"
- "Each cell has a 90-second wall-clock time limit; code that exceeds it returns a detection_timeout result"

File types accepted via Files API:
"The Python environment can process various file types uploaded through the Files API, including:
- CSV
- Excel (.xlsx, .xls)
- JSON
- XML
- Images (JPEG, PNG, GIF, WebP)
- Text files (.txt, .md, .py, and others)"

Model compatibility:
- claude-sonnet-4-6: code_execution_20250825, code_execution_20260120, code_execution_20260521
- claude-opus-4-8: code_execution_20250825, code_execution_20260120, code_execution_20260521
- claude-haiku-4-5: code_execution_20250825 only

Platform availability:
"Code execution is available on: Claude API (Anthropic), Claude Platform on AWS, Microsoft Foundry"
"Code execution is not currently available on Amazon Bedrock or Vertex AI."

NOT ZDR eligible:
"This feature is not eligible for Zero Data Retention (ZDR). Data is retained according to the feature's standard retention policy."

Use when code benefits computation:
"Claude runs code when the request benefits from computation or file handling:
- Non-trivial math (large numbers, many steps, precision-sensitive results)
- Data analysis, file parsing, or visualization
- Algorithm execution or simulation
- Explicit requests to 'run', 'compute', or 'execute'"

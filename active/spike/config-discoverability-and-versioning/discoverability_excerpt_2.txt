SOURCE: ~/.claude/scripts/inject-output-policy-reminder.sh (full file)
PURPOSE: Shows the minimal-reminder injection pattern

---
reminder=$(cat <<'EOF'
=== OUTPUT POLICY REMINDER ===

Before producing output this turn, check the destination:

- Research findings / code review / comparisons / decision matrices / timelines → render HTML ...
- LLM-consumed planning docs ... → markdown in ~/.claude/plans/active/<topic>/.
- ...
EOF
)

jq -n --arg ctx "$reminder" '{
    hookSpecificOutput: {
        hookEventName: "UserPromptSubmit",
        additionalContext: $ctx
    }
}'
---

OBSERVATION: Pattern for "stateless reminder on every prompt" is already
in production in this repo. A capability-tip hook would follow the exact
same shape. The risk is additive token cost: three hooks already inject
context unconditionally on every prompt. A fourth adds to context size.

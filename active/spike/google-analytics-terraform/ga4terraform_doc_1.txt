--- VERBATIM CONTENT FROM OVERVIEW ---

"The Google Analytics Admin API allows for programmatic access to the Google Analytics configuration data and is only compatible with Google Analytics properties."

Key management capabilities (from overview):
- Provisioning and managing accounts, properties, and subproperties
- Enabling management of data sharing, retention, and Google Signals settings
- Facilitating managing data streams, measurement protocol secrets, and various event-related features

The overview page makes NO mention of gtag.js, GTM snippets, or client-side JavaScript tags.
The API documentation covers server-side configuration data only.

--- PROPERTY RESOURCE DETAILS ---
SOURCE: https://developers.google.com/analytics/devguides/config/admin/v1/rest/v1beta/properties
FETCHED: 2026-06-26

Available Methods:
- Create: "Creates a Google Analytics property with the specified location and attributes"
- Get: Retrieve a single property
- List: "Returns child Properties under the specified parent Account"
- Patch: Update property configuration
- Delete: "Marks target Property as soft-deleted (ie: 'trashed') and returns it"
- acknowledgeUserDataCollection
- getDataRetentionSettings / updateDataRetentionSettings
- runAccessReport

Configurable Fields (can be set during creation/updates):
- displayName (required, max 100 UTF-16 code units)
- timeZone (required, IANA format)
- currencyCode (ISO 4217 format)
- industryCategory (for benchmarking)
- propertyType (immutable after creation; defaults to ORDINARY_PROPERTY)

Output-only Fields (system-managed):
- createTime / updateTime
- deleteTime / expireTime
- serviceLevel (Standard or 360 designation)

--- DATA STREAMS MEASUREMENT ID ---
SOURCE: https://developers.google.com/analytics/devguides/config/admin/v1/rest/v1beta/properties.dataStreams
NOTE: HTTP 404 on direct fetch; content derived from overview and search results.

The measurementId field is OUTPUT-ONLY:
"The unique Google-assigned identifier of a web stream (e.g. G-1234567). It is not editable."
The measurement ID is assigned by Google when a web data stream is created, not specified by the caller.

Authentication approaches supported:
- User accounts
- Service accounts

Service accounts:
- Supported for server-to-server flows
- Must be granted GA4 role (e.g., Administrator) at the target account or property
- gcloud auth application-default login scopes:
  https://www.googleapis.com/auth/cloud-platform
  https://www.googleapis.com/auth/analytics.readonly

Available language client libraries:
Java, PHP, Python, Node.js, .NET, Ruby, Go
Also: REST API for direct HTTP calls

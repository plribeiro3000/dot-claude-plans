--- GIST: Terraform-google-analytics ---
URL: https://gist.github.com/salrashid123/e6366a551ce952b603036dbd996b7768
Last active: July 27, 2020

This is NOT a Terraform provider for Google Analytics.
It is a workaround attempting to use Terraform's HTTP data source to emit tracking events via Measurement Protocol.
It uses: random_id resource for client ID, http data source to POST tracking requests.
Known issue: HTTP provider accepts only certain content types; GA returns image/jpg (tracking pixel) causing incompatibility.
Status: Experimental/non-functional. Serves as documentation of a failed approach, not a working solution.

--- AIRBYTE PROVIDER ---
URL: https://registry.terraform.io/providers/airbytehq/airbyte/latest/docs/resources/source_google_analytics_data_api
This is an Airbyte connector resource for DATA EXTRACTION (reading GA4 reporting data into Airbyte pipelines).
It is NOT for GA4 Admin API configuration management.
It does not create/manage properties, data streams, custom dimensions, or any admin config.

--- GOOGLE ANALYTICS UTILITIES ---
URL: https://github.com/google/google-analytics-utilities
Description: "This is not an officially supported Google product."
Technology: Google Apps Script (runs in Google Sheets)
Resources managed: Properties, data streams, custom dimensions, custom metrics, key events, audiences, integrations
What it IS: A spreadsheet-based bulk management tool for GA4, NOT a Terraform provider or IaC tool
Maintenance: Actively maintained; last release October 28, 2024; 247 stars, 34 forks, 12 releases

--- GA4 MANAGER ---
URL: https://www.oscargallegoruiz.com/en/blog/ga4-manager-automate-google-analytics/
Technology: Go CLI tool and MCP server
API used: Google Analytics Admin API v1alpha
Approach: YAML-declarative (not Terraform)
What it manages: GA4 property configuration (conversions, dimensions, metrics, data retention), Search Console
Limitations:
- "Cannot migrate historical data; collection starts after setup"
- "Audience creation requires manual UI completion"
- "Search Console linking is manual"
- "BigQuery linking is automated, but parameter names are permanently reserved once created"
- "Free tier capped at 30 conversions, 50 dimensions, 50 metrics"
Status: Active open-source project

--- MARKETING ANALYTICS JUMPSTART (GCP) ---
URL: https://github.com/GoogleCloudPlatform/marketing-analytics-jumpstart
Technology: Terraform for GCP infrastructure (BigQuery, Vertex AI, Dataform)
Note: Uses Terraform to deploy GCP infrastructure that RECEIVES GA4 BigQuery export data.
Does NOT manage GA4 properties or Admin API configuration.
The Terraform here is about the data pipeline stack, not GA4 admin config.

Observation: `Bash(git:*)` already auto-approves `git commit ...` in any
shape. A validate-commit-message.sh PreToolUse hook would need to actively
emit exit code 2 (hard block, mirrors validate-bash-command.sh's existing
blocks) to override this broad allow — a passive "ask" reclassification is
not enough, because "ask" still lets the engineer rubber-stamp a malformed
message. Exit-2 block is the shape already used for git safety blocks in
validate-bash-command.sh (reset --hard, branch -D, checkout ., etc.).

## Slack's Design Pattern

Slack uses the SAME EMAIL across MULTIPLE WORKSPACES (tenants), with a workspace selector
at login. This is the canonical real-world reference for Option B (tenant-aware auth).

Key characteristics:
- Email is NOT globally unique across workspaces
- Each workspace = separate account (separate identity per workspace)
- The Slack app is the "session manager that holds all those sign ins"
- Password reset sends a code that covers all workspaces for that email — tenant
  discovery is done AFTER authentication, not before

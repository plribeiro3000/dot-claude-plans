VERBATIM QUOTE (Auth0 community moderator Rueben Tiow):
"If you had Database A and Database B configured, you could have a user with the same
email address in each of those database connections."

## Auth0 Position on Email Uniqueness

Auth0 enforces email uniqueness at the CONNECTION level (analogous to a tenant's user pool),
not globally across all connections. The same email CAN exist in multiple connections.

When a question asked about the same email for multiple users, the Auth0 moderator's
confirmed answer was: create separate database connections per data source.

## Summary

Auth0's organizational model enforces isolation per organization. The same email can exist
in different Auth0 connections (the database-level unit of isolation). Auth0 does not enforce
global email uniqueness across all its tenants.

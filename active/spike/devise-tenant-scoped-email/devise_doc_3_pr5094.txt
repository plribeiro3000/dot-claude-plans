## What the PR Proposes

The pull request aims to add an `email_scope` option to Devise's email uniqueness validator,
enabling developers to scope email validation to specific attributes. This addresses multi-tenancy
scenarios where multiple users across different tenants should be able to share the same email
address.

As stated in the original description, use cases include:
- Per-subdomain authentication
- Soft deletion support
- Username-based sign-in alternatives

**Recoverable Module Incompatibility**: The same contributor warned:
VERBATIM QUOTE: "the 'recoverable' module may not work well...as it will only include a

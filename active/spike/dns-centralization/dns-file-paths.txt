=== CROSS-PROJECT COMMUNICATION MECHANISMS ===

1. SSM PARAMETERS (Primary)
   - Networking infrastructure published via AWS Systems Manager Parameter Store
   - Structured as: /networking/{environment}/{resource_type}
   - Read by modules/networking_data module
   - Used by all app and integrator projects

2. LOCAL MODULES (Same-stack references)
   - Projects reference modules in ../modules/ locally
   - ALB DNS available via module.public_alb.alb_dns_name
   - Only works within same Terraform state/stack

3. HARDCODED DNS (Cross-project)
   - DNS project contains hardcoded ALB DNS names
   - Values extracted from deployed infrastructure
   - Manual process required after ALB creation

4. TERRAMATE DEPENDENCIES
   - Stack execution ordering via "after" property
   - Ensures networking runs before app environments
   - Ensures apps run before dns
   - NOT used for data sharing

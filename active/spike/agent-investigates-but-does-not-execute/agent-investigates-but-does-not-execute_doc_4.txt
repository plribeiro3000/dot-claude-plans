### Research-First Policy

- NEVER answer questions from training data alone — always verify with a real source first
- Questions about the codebase (behavior, structure, configuration): use Grep/Read/Glob BEFORE responding
- Questions about external tools, libraries, APIs, error messages: use WebSearch BEFORE responding
- If you cannot find evidence: say "I did not find this" — NEVER fill the gap with a guess
- When the engineer asks "what could this be?" or "why is this happening?": investigate the code and/or search the web — do not theorize from training data
---
ANALYSIS OF ASYMMETRY: The policy frames its gate as "BEFORE responding" — a response to an engineer's question. The trigger condition throughout is "the engineer asks" or "answer questions from." The policy is silent on the AskUserQuestion moment — when the agent itself is generating technical options or a recommendation to surface to the engineer. The agent can invoke AskUserQuestion with option A, B, C derived from parametric knowledge (training data) without any WebSearch, and nothing in CLAUDE.md or ASK-DONT-DECIDE.md currently requires external research at that moment.

### storage.dek — key wrapper file

Command: python3 -c "with open(path, 'rb') as f: d = f.read(); print(d.hex()); print(repr(d))"
Size:    51 bytes
Hex:     76313042eb36c8208fc225a4672faeaafd73248d1ea11987890881cd5162b37b585e9b0ed5caec565dd4ddaa456325bfbb7312
ASCII:   b'v10B\xeb6\xc8 \x8f\xc2%\xa4g/\xae\xaa\xfds$\x8d\x1e\xa1\x19\x87\x89\x08\x81\xcdQb\xb3{X^\x9b\x0e\xd5\xca\xecV]\xd4\xdd\xaaEc%\xbf\xbbs\x12'

First 4 bytes ASCII: "v10B"

This is the Electron/Chromium safeStorage prefix format:
  - "v10" = version tag used by Electron safeStorage on macOS
  - Following bytes = AES-GCM ciphertext (encrypted with macOS Keychain key)
  - The Keychain entry name for Granola is "Granola Safe Storage"

The safeStorage prefix v10 on macOS means:
  - The plaintext key (DEK) was encrypted with a key stored in the macOS Keychain
  - The Keychain item service name is "Granola Safe Storage"
  - To decrypt: retrieve the raw key from Keychain → use it as AES-128-GCM key
    to decrypt the 47 bytes following "v10" → that yields the actual DEK
  - The DEK then decrypts cache-v6.json.enc, supabase.json.enc, granola.db, etc.

References:
  - Electron safeStorage docs: https://www.electronjs.org/docs/latest/api/safe-storage
  - Chrome OSCrypt / v10 prefix: https://source.chromium.org/chromium/chromium/src/+/main:components/os_crypt/
  - Chrome decryption in Python (v10 pattern): https://n8henrie.com/2014/05/decrypt-chrome-cookies-with-python/

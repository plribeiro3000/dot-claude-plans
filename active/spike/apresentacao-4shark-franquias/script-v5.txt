GAMMA.APP LIMITATIONS DISCOVERED DURING V5 BUILD

- Nao aceita instrucao de "deixar area de imagem vazia" — sempre gera alguma imagem
- Nao consegue aplicar cores de fundo personalizadas em cards individuais via prompt
- Edicoes de texto via prompt as vezes quebram layout — preferir edicao manual para alteracoes pontuais
- Prompt para trocar apenas texto de um elemento: incluir "Nao altere layout, visual ou estrutura" explicitamente
- Undo (Cmd+Z) disponivel, redo nao disponivel

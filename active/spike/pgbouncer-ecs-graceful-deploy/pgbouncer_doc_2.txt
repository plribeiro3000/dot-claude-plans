=== POOL_MODE ===

pool_mode
  Specifies when a server connection can be reused by other clients.
  transaction: Server is released back to pool after transaction finishes.
  Default: session

=== SERVER TIMEOUTS ===

server_idle_timeout
  If a server connection has been idle more than this many seconds it will be
  closed. If 0 then this timeout is disabled. [seconds]
  Default: 600.0

server_lifetime
  The pooler will close an unused (not currently linked to any client
  connection) server connection that has been connected longer than this.
  Setting it to 0 means the connection is to be used only once, then closed.
  [seconds]
  Default: 3600.0

client_idle_timeout
  Client connections idling longer than this many seconds are closed. This
  should be larger than the client-side connection lifetime settings, and only
  used for network problems. [seconds]
  Default: 0.0 (disabled)

max_client_conn
  Maximum number of client connections allowed.
  Default: 100

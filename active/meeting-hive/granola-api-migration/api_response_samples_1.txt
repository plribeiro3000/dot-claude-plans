## Field mapping: old cache → new API

| Pipeline uses       | Old cache path                        | New API path (detail)             |
|---------------------|---------------------------------------|-----------------------------------|
| Meeting.id          | doc_id (dict key)                     | note["id"]                        |
| Meeting.title       | doc["title"]                          | note["title"]                     |
| Meeting.attendees   | doc["people"]["attendees"][]["email"] | note["attendees"][]["email"]      |
| Meeting.created_at  | doc["created_at"]                     | note["created_at"]                |
| Meeting.duration_seconds | not in old cache either          | computable from calendar_event    |
| transcript segment  | segments[]["text"]                    | transcript[]["text"]              |
| segment timestamp   | segments[]["start_timestamp"]         | transcript[]["start_time"]        |
| Granola summary     | not available                         | note["summary_markdown"]          |
